Token do GitHub

Sem "lembrar", o token fica só na memória desta aba e some ao fechá-la. Com "lembrar", fica guardado no navegador deste aparelho. Como as outras páginas do site carregam um contador de acessos de terceiros, não marque essa opção em aparelhos compartilhados.

  1. No GitHub, abra Settings → Developer settings → Personal access tokens → Fine-grained tokens e clique em Generate new token.
  2. Em Repository access, escolha Only select repositories e marque só este repositório.
  3. Em Permissions → Repository permissions, coloque Contents: Read and write. Nenhuma outra permissão.
  4. Defina uma validade (por exemplo, 90 dias), gere o token e copie.
